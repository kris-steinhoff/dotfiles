# Herdr app settings

This file covers which of the Herdr desktop app's files these dotfiles manage and why; load it before changing anything in this directory.

The Herdr desktop app (`herdr-app`) keeps its whole interface as files in `~/.config/herdr-app/`, and its Settings screen writes `settings.json` itself (zoom, appearance, contrast, telemetry). So that file's source is a chezmoi modify-template, `modify_settings.json`, which reads the live file and sets only the keys we manage, as the `modify_` scripts for Claude's and Codex's settings do; it needs no interpreter because chezmoi's own `fromJson` and `setValueAtPath` are enough. The app ships no Tokyo Night, so `themes/tokyo-night.json` is ours; the app leaves theme files it didn't write alone. Keys stay on the app's defaults, and the shipped layouts and mods are left unmanaged, because Herdr replaces them on every start and personal changes to them go through clones.

`layouts/personal.json` is that kind of clone: the shipped `main` layout copied as-is, plus an `ai-usage` block between the sidebar lists and the Settings footer. It is a snapshot, so changes Herdr later makes to `main` don't reach it; to pick them up, re-copy `main.json` and re-insert the block. The block shows `mods/ai-usage/`, which runs `~/.local/bin/ai-usage --json windows` every minute. That is cheap because the script's shared cache decides when the providers are actually asked (see `dot_local/bin/AGENTS.md`). The mod resizes its own block to fit however many services and windows report, and clicking it opens a tab with the live `ai-usage` view. The older terminal Herdr's `~/.config/herdr/config.toml` is a separate program's config and stays as it is.
