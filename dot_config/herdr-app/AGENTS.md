# Herdr app settings

This file covers which of the Herdr desktop app's files these dotfiles manage and why; load it before changing anything in this directory.

The Herdr desktop app (`herdr-app`) keeps its whole interface as files in `~/.config/herdr-app/`, and its Settings screen writes `settings.json` itself (zoom, appearance, contrast, telemetry). So that file's source is a chezmoi modify-template, `modify_settings.json`, which reads the live file and sets only the keys we manage, as the `modify_` scripts for Claude's and Codex's settings do; it needs no interpreter because chezmoi's own `fromJson` and `setValueAtPath` are enough. The app ships no Tokyo Night, so `themes/tokyo-night.json` is ours; the app leaves theme files it didn't write alone. Keys stay on the app's defaults, and the shipped layouts and mods are left unmanaged, because Herdr replaces them on every start and personal changes to them go through clones.

`layouts/personal.json` is that kind of clone: the shipped `main` layout copied as-is, except that its bottom bar (the `status` block) becomes a `status-row` row holding that block and an `ai-usage` block at its right end. It is a snapshot, so changes Herdr later makes to `main` don't reach it; to pick them up, re-copy `main.json` and wrap `status` again. The block shows `mods/ai-usage/`, which runs `~/.local/bin/ai-usage --json windows` every minute. That is cheap because the script's shared cache decides when the providers are actually asked (see `dot_local/bin/AGENTS.md`). Each service is one unlabeled glyph of nested rings, one per limit window with the longest outside, painted with gpui-kit's `PathBuilder` so any percent draws in theme colors; hovering names the service and gives the numbers. Color goes by pace (where the window ends up at the current rate) rather than the raw percent, because a high weekly figure late in the week is normal while a modest 5-hour figure early in the window is the real warning. A layout block can't size itself to its content, so the mod measures its content and resizes its own block's width to fit; clicking it switches to the tab named "AI usage" if one exists, else opens one running the live `ai-usage` view. `programs.json` gives that terminal its own name and icon (`mods/ai-usage/icon.svg`); without the entry Herdr, which looks through uv to the script it runs, finds no `ai-usage` program and shows uv's icon. The older terminal Herdr's `~/.config/herdr/config.toml` is a separate program's config and stays as it is.
